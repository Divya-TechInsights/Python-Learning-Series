-------------------------INTRODUCTION TO PYTHON-----------------------




1. What is Python

* Python is a high-level, interpreted programming language.

* Python is a high-level language because:

  - It uses simple, human-readable syntax
  - It hides hardware and memory details
  - Memory management is automatic
  - It is platform independent
  - Code is executed by an interpreter, not directly by hardware
  - It provides built-in functions and libraries
  
These features let programmers focus on logic, 
not machine-level details.


One-line version:
“Python is a simple, powerful programming language used to build 
real-world applications.”

4. Features of Python

* Simple and easy to learn – English-like syntax
* High-level language – hides hardware details
* Interpreted – executes code line by line
* Platform independent – runs on Windows, Linux, macOS
* Dynamically typed – no need to declare data types
* Object-oriented – supports classes and objects
* Large standard library – many built-in modules
* Open source – free to use and modify
* Extensible & embeddable – can work with other languages

7. How Python Works

1. We write Python code in a file (.py)
2. The Python interpreter reads the code
3. Code is checked and converted to bytecode
4. Bytecode is executed line by line
5. The computer produces output

In short:
Python code → Interpreter → Execution → Output

Note - We don’t need to compile Python manually; 
it runs directly using the interpreter.

(Compile means converting high-level programming code into 
machine-readable code so the computer can execute it.)
